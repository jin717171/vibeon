알아두면 좋은 단어

바이브 코딩

원하는 기능을 자연어로 AI에게 설명하고, AI가 생성한 코드를 실행·확인·수정하며 만드는 방식이에요.

프롬프트

AI에게 어떤 결과를 만들어 달라고 요청하는 지시문이에요. 자세할수록 결과를 확인하고 고치기 쉬워요.

HTML · CSS · JavaScript

HTML은 내용과 구조, CSS는 디자인, JavaScript는 버튼·입력·저장 등 동작을 담당해요.

데이터베이스 / Supabase

데이터를 구조적으로 저장하고 불러오는 곳이에요. Supabase는 이를 온라인으로 제공하는 서비스예요.

GitHub / GitHub Pages

GitHub는 코드 파일을 관리하는 서비스이고, GitHub Pages는 코드를 정적 웹사이트로 공개하는 호스팅 기능이에요.

localStorage

현재 브라우저에 소량의 정보를 저장하는 기능이에요. 서버와 자동 연결되거나 다른 기기로 동기화되지 않아요.

Project URL / Publishable key / RLS

Supabase에 연결할 프로젝트 주소, 브라우저에서 사용 가능한 공개용 키, 데이터 접근 권한을 제한하는 행 단위 보안 규칙이에요.

자주 묻는 질문

코딩을 몰라도 사용할 수 있나요?

네. 화면에 나온 질문을 자신의 말로 채우면 제작 프롬프트를 만들 수 있어요. 생성한 코드는 직접 실행하며 원하는 결과인지 확인해야 해요.

내 기획이 어디에 저장되나요?

현재 기기의 이 브라우저 localStorage에만 저장돼요. 브라우저 데이터 삭제, 시크릿 모드 사용, 저장 공간 부족 등으로 내용이 사라질 수 있으므로 완성한 프롬프트를 TXT로 보관하세요.

다른 기기에서도 이어서 할 수 있나요?

아니요. 이 첫 버전에는 로그인이나 온라인 동기화가 없어요. Supabase를 실제로 연결하고 사용자별 저장 기능을 개발해야 다른 기기에서 불러올 수 있어요.

이미지 파일도 AI 프롬프트에 포함되나요?

프롬프트에는 이미지 개수만 적혀요. 그림 자체는 텍스트로 전달되지 않으므로 ChatGPT 대화창에 별도로 업로드해야 해요.

GitHub에 올리면 데이터도 온라인 저장되나요?

아니요. GitHub Pages는 웹페이지를 공개하는 기능이에요. 공유 데이터 저장을 원하면 Supabase 등의 데이터베이스를 별도로 연결해야 해요.

Supabase 키는 HTML에 넣어도 되나요?

Publishable key는 공개 웹페이지에서 사용할 수 있지만 반드시 RLS 권한을 안전하게 설정해야 해요. Secret key나 service_role 키는 절대로 HTML이나 공개 저장소에 넣으면 안 돼요.

페이지가 열리지 않거나 버튼이 작동하지 않아요.

파일명이 index.html인지, 확장자가 .txt로 저장되지 않았는지 확인하세요. 인터넷 연결이 필요한 기능은 파일만 열어서 사용하기 어려울 수 있어요. 브라우저 개발자 도구에서 오류를 확인하고 AI에 오류 문구를 전달하세요.
